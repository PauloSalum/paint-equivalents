Privacy policy

What this site collects

Nothing directly. Every page here is a static file. There is no account, no login, no form and no server-side code, so nothing you type into the search box or the colour finder is transmitted anywhere — both run entirely in your browser against a file the page downloads.

Hosting

The site is served by GitHub Pages. Like any web host, GitHub receives the requests your browser makes, including your IP address and user agent, and may log them. That is described in the GitHub Privacy Statement.
