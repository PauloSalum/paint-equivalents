    How the matching works

    Each paint carries a measured sRGB value, converted to CIELAB — a colour space built so that equal numeric distances look like equal differences to the eye. Every pot is then compared to every other pot with CIEDE2000, and the nearest one in each range is what you see.

    The number beside each match is ΔE. Read it like this:

    < 1indistinguishableyou would not spot the swap on a finished model
    1–2near-perfectsafe for a straight substitution
    2–3.5very closefine unless the two sit edge to edge
    3.5–5closevisible side by side, usually fine as a base
    5–10similarsame family, different colour
    > 10farthe range simply has nothing like it

    These are screen approximations of physical paint. Pigment, finish and opacity are not captured by a hex value, so treat a match as a shortlist, not a promise.
